# Kriegspiel Avalon

A browser adaptation of Avalon Hill’s 1970 Kriegspiel, with artwork for building a table in Tabletop Simulator.

- [Browser game](Kriegspiel-Public/README.md) · Run `node Kriegspiel-Public/server.mjs` and open http://127.0.0.1:4173. The Windows launcher is also in that folder.
- [Tabletop Simulator asset pack](Kriegspiel-TTS-Assets/IMPORT.md) · Includes classic boards, paired division images and bulk sheets, tactics, markers, and player aids.
- [Artwork credits and license](Kriegspiel-Public/ARTWORK.md) · The tracked classic artwork and rules use CC BY-SA 4.0. The TTS deck sheets include adaptations of the printed tactic chits.
